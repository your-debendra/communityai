# Contributing

Thanks for your interest in improving CommunityAI!

## Before you start

- Search existing issues to avoid duplicates.
- For a major change, open an issue first to discuss the idea.
- Keep changes focused and explain the problem they solve.

## Making a contribution

1. Fork the repository.
2. Create a branch: `git checkout -b feature/your-change`.
3. Make and test your changes in a browser.
4. Commit with a clear message.
5. Open a pull request describing what changed and how you tested it.

## Guidelines

- Use semantic HTML and accessible labels.
- Keep the project dependency-free unless a dependency is justified.
- Do not add tracking or collect personal information without clearly documenting it.
- Verify external links before adding them.
